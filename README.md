# 🍗 JamesGrill House

**Food Made With Love**

JamesGrill House is a modern restaurant website designed to provide customers with a simple and engaging way to discover meals, browse the menu, add items to their cart, and place food orders online.

The website combines a clean restaurant focused design with interactive features to create a convenient digital ordering experience.

## 🌐 Live Website

**[Visit JamesGrill House](https://kobijames18.github.io/JamesGrill-Food/)**

---

## ✨ Features

### 🏠 Home Page

* Modern restaurant landing page
* Hero section with restaurant introduction
* Featured meals
* Popular food categories
* Call to action buttons for ordering
* Restaurant branding and information

### 🍽️ Menu

* Browse available meals
* Organized food categories
* Search functionality
* Food descriptions and pricing
* Easy access to individual menu items

### 🛒 Shopping Cart

* Add food items to the cart
* Review selected items
* Update quantities
* Remove items
* View the order total

### 💳 Checkout

* Customer checkout experience
* Order information collection
* Delivery details
* Order confirmation flow

### 📦 Order History

* Customers can access previous orders
* View their order information after purchasing

### ⭐ Customer Reviews

* Customers can submit reviews
* Rating system
* Review moderation before displaying submissions

### 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 📱 Mobile phones
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop computers

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/KobiJames18/JamesGrill-Food.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd JamesGrill-Food
```

### 3. Run the website

Open `index.html` in a browser, or use a local development server such as **VS Code Live Server**.
